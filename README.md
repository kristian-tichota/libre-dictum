# Overview

A quick disclaimer: most of the code, including `docs` and `specs` folders, are generated by an LLM. Nonetheless, this program is the author's daily input driver for GNU/Linux and could prove useful for others with hand-related issues.

A minimalist accessibility tool for GNU/Linux. It bridges local speech recognition with
kernel-level input simulation, which bypasses the limitations of any specific window manager or
desktop environment.

https://github.com/user-attachments/assets/c7735d22-9583-4e38-a2c0-72d622a4153f

## Features

* **Kernel-level input**: `python-evdev` injects keystrokes into the input subsystem
  directly.
* **Local processing**: every model runs locally.
* **Hybrid transcription**: VOSK models with a grammar built from the configured commands & transformer models for dictation.
* **Mode switching**: modes are switched by voice or gesture commands while the session runs.
* **Configurability**: the command structure is fully configurable.
* **Gesture recognition**: define custom hand and facial gestures.
* **System tray**: live feedback of the current program state.
* **On-screen display**: a persistent chip showing the program state.
* **Script execution**: arbitrary scripts can run from any command.

## Quick start

**1. Install [uv](https://docs.astral.sh/uv/).** It manages the Python version and every
dependency, and it is the only component to install by hand.

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**2. Install libre-dictum** from the root of the repository.

```bash
uv sync
```

**3. Allow keystrokes.** Typing goes through `/dev/uinput`, which needs permission. Log out and
back in afterwards.

```bash
sudo usermod -aG input $USER
```

**4. Download a speech model.** Take `vosk-model-small-en-us-0.15` from
[VOSK](https://alphacephei.com/vosk/models) and unpack it. A mode names that folder in its `path`
setting.

**5. Write a configuration file.** Copy an [example](./examples/configs/) to
`~/.config/libre-dictum/config.json` and edit it. Without one the program does nothing.

**6. Run it.**

```bash
uv run libre-dictum -v
```

## Configuration

One JSON file holds everything. It lists modes, and each mode lists the commands it answers. A
command maps a spoken phrase to a response, such as a keystroke, a script or a mode switch.

| Page | Covers |
|---|---|
| [Configuration reference](./docs/reference/configuration.md) | Every setting and its default |
| [Response DSL](./docs/reference/response-dsl.md) | The language a command maps to |
| [Calibration order](./docs/reference/calibration.md) | Camera, pointer, screen, hands and face |
| [`examples/configs/`](./examples/configs/) | Working files to start from |

A large configuration can be split. `config.json` lists other files in its `include` array, as in
[`examples/configs/split/`](./examples/configs/split).

## Optional features

Each feature is an extra. Name every extra needed in one command, because a sync makes the
environment match exactly what was asked for.

```bash
uv sync --extra head-tracking --extra overlay
uv sync --extra all
```

| Extra | Enables |
|---|---|
| `system-tray` | The active mode as a coloured circle in the system tray. |
| `overlay` | The on-screen chip and command sheet. |
| `head-tracking` | Pointer movement from head rotation, plus hand and facial gestures. |
| `pedals` | Foot pedals, read from a USB HID board. |
| `whisper` | Dictation with openai-whisper. |
| `transformers` | Dictation with any transformer model. |
| `all` | All six of the above. |

Four of them need one more step.

### Head tracking

Download
[`face_landmarker.task`](https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/latest/face_landmarker.task)
and point `ht_model_path` at it. Hand gestures need
[`hand_landmarker.task`](https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task)
as well. Then follow [calibration order](./docs/reference/calibration.md).

### On-screen display

GTK4 and `gtk4-layer-shell` come from the distribution. On some distributions the GObject
introspection binding is a separate package.

```bash
sudo apt install python3-gi libgtk-4-1 libgtk4-layer-shell0 gir1.2-gtk4layershell-1.0
sudo dnf install gtk4-layer-shell
```

The display is a second program. Run both, and keep them at the same version.

```bash
uv run libre-dictum &
uv run libre-dictum-hud
```

`libre-dictum-hud --probe` reports what the compositor granted and prints the fix for anything
missing. The phrases and flags are in
[the reference](./docs/reference/configuration.md#the-on-screen-display).

### Foot pedals

Reading the board needs a udev rule. This one is for the Elgato Stream Deck Pedal, which is the
default board.

```bash
echo 'SUBSYSTEM=="hidraw", ATTRS{idVendor}=="0fd9", ATTRS{idProduct}=="0086", TAG+="uaccess"' \
  | sudo tee /etc/udev/rules.d/70-libre-dictum-pedals.rules
sudo udevadm control --reload-rules && sudo udevadm trigger
```

A headless machine needs `MODE="0660", GROUP="input"` instead of `uaccess`.

### Dictation

Both dictation extras pull in PyTorch. The wheel on PyPI is the CUDA build. Any other accelerator
needs the matching build, and the step repeats after every later `uv sync`.

```bash
uv pip install torch --torch-backend=auto
```

## Start at login

Two [systemd user units](./examples/systemd/), one per program.

```bash
mkdir -p ~/.config/systemd/user
cp examples/systemd/libre-dictum*.service ~/.config/systemd/user/
sed -i "s|%h/libre-dictum|$PWD|" ~/.config/systemd/user/libre-dictum*.service
systemctl --user daemon-reload
systemctl --user enable --now libre-dictum.service
systemctl --user enable --now libre-dictum-hud.service   # only with the overlay extra
```

`journalctl --user -u libre-dictum -f` is the log. After a rejected configuration, run
`systemctl --user reset-failed libre-dictum`.

## Development

```bash
uv run pytest
uv run ruff check src tests
uv run black src tests
uv run mypy
```

The suite needs no microphone, camera, model or `/dev/uinput`. [`specs/`](./specs) describes the
behaviour in Gherkin, [`tests/`](./tests) mirrors it, and [`docs/`](./docs) explains what no single
file shows.

## Limitations

This is version 0.1.0 and the configuration format still changes between releases. Open defects
are listed in [known gaps](./docs/development/known-gaps.md), and two of them affect hands-free
recovery.

Webcam capture defaults to MJPG at 1920x1080 and 60 fps. If head tracking does not start, override
`ht_capture_fourcc`, `ht_capture_width`, `ht_capture_height` and `ht_capture_fps`.
